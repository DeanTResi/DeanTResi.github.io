Manual instructions (without this page)

Prepare the pictures

  1. Make each picture file 2 times its display size. For example, a 28 × 28 icon must be a 56 × 56 file.
  2. Upload the files to Google Drive. Share each file as Anyone with the link.
  3. Get each picture address. Use one of these methods:
    • Copy the Drive share link, for example https://drive.google.com/file/d/FILE_ID/view. Use https://lh3.googleusercontent.com/d/FILE_ID as the picture address.
    • In the Gmail signature box, use Insert image → Google Drive. Right-click the picture → Copy image address. Then delete the picture from the box.
  4. Open each picture address in a private browser window. If the picture does not show, the file is not shared correctly.

Make the signature

  1. Click Copy code below.
  2. Paste the code into a plain text editor: Notepad on Windows, or TextEdit on Mac. In TextEdit, first select Format → Make Plain Text.
  3. Replace every value in capital letters with your own value. Some values appear more than once: replace every copy. The table below the code explains each value.
  4. Save the file as signature.html.
  5. Open signature.html in Chrome. Check that all pictures show.
  6. Select all (Ctrl+A or Cmd+A) and copy (Ctrl+C or Cmd+C).
  7. In Gmail, go to Settings → See all settings → General → Signature. Delete the old signature, paste, and click Save changes.
  8. Send yourself a test email. Open it in Gmail and in Apple Mail or Outlook, and check that it looks the same.
